# FreeGFW 单机配额版

基于 FreeGFW 的单机代理管理面板，使用 Sing-box 和 Xray 核心，支持模板部署、用户连接管理和月度流量配额。

**[打开完整部署与使用说明](https://gyj-gif.github.io/freegfw-quota/)**

## 功能

- **一键安装与升级**：无需预装原版；自动识别新装或已有 Docker 实例。缺少 Docker 时自动安装。
- **协议模板**：支持 VLESS / Reality / Vision、XHTTP、Hysteria2、NaiveProxy、VMess、Shadowsocks 等模板，按客户端兼容性选择。
- **用户连接管理**：添加独立用户，设置限速，通过二维码或连接 / 订阅链接导入客户端。
- **月度流量配额**：每位用户独立设定额度，上传与下载合计，超额断连，下个周期自动恢复。
- **可选 WARP 出站**：在系统设置中启用或关闭 Cloudflare WARP 出站隧道。
- **备份与回退**：升级前备份数据，保留原容器和原数据卷，并提供回退脚本。

本版用于单台 Linux 服务器的本地用户，不支持节点互联、跨节点共享额度、Systemd 安装或非 host 网络的现有实例。

## 一键部署

通过 SSH 登录 Linux 服务器，以 root 执行：

```bash
curl -fSL https://raw.githubusercontent.com/GYJ-gif/freegfw-quota/main/install-quota.sh -o install-quota.sh && bash install-quota.sh
```

支持 amd64 / arm64。服务器需有 `curl`、`tar`、`sha256sum`、`base64`、`mktemp` 和 `flock`；全新安装还需 `ss`（通常由 iproute2 / iproute 提供）。首次会在服务器构建镜像，请预留内存、磁盘和下载编译时间。

默认面板地址：`http://服务器IP:8080`。如需自定义端口，先下载脚本，再执行：

```bash
env FREEGFW_PANEL_PORT=18080 bash install-quota.sh
```

请在云安全组和服务器防火墙放行面板及实际节点端口。脚本不会修改防火墙或 SSH。

已有实例需满足：容器名为 `freegfw`、正常运行、使用 host 网络、有 `/data` 持久化挂载，且面板已设置账号。升级时填写原面板端口，继续使用原账号、节点配置、证书和订阅标识。

## 首次使用

1. 打开面板，在“系统设置 → 基本设置”设置管理员用户名和密码。初始化前面板没有登录保护。
2. 按首次部署引导配置证书，选择“我是新手”，从内置模板中选择客户端支持的协议并部署。
3. 在“本地用户管理”添加独立用户，设置限速和月度额度。
4. 打开该用户的“连接码”，扫码或复制连接 / 订阅链接，导入兼容客户端。
5. 用一个小额度测试用户验证上传、下载计量、超额断连及提高额度后的恢复，再正式使用。

需要 WARP 时，在“系统设置 → 基本设置”勾选“启用 Cloudflare WARP 出站隧道”并保存。是否能访问特定服务取决于出口和目标服务策略。

## 配额规则

| 项目 | 规则 |
| --- | --- |
| 新增用户 | 默认 150 GB / 月，可修改；0 表示不限额 |
| 旧用户升级 | 未设置配额的用户默认不限额；已有额度及当期用量保留 |
| 计量方式 | 上传 + 下载；1 GB = 1,000,000,000 字节 |
| 重置时间 | 每月 2 日北京时间 00:00；首次启用从零计量 |
| 超额处理 | 断开连接并拒绝新连接；下个周期或提高额度后恢复 |
| 用量保存 | 正常退出保存；强杀或断电可能丢失最后约一秒用量，并发流量可能造成少量超额 |

累计历史流量不等于当期配额用量。Vision 计量会关闭绕过计量的快速复制路径，可能增加 CPU 使用。

## 升级与回退

更新时重新运行本页的配额版脚本，不要使用原版安装脚本覆盖更新。

升级先构建镜像，再短暂停机并将 `/data` 备份到 `/opt/freegfw-quota/backups/`。新版使用独立数据副本，保留原容器和原数据卷；失败时尝试自动恢复旧容器。

升级成功后会输出 `rollback.sh` 的完整路径。需要回退时执行该文件：

```bash
bash /opt/freegfw-quota/backups/实际备份目录/rollback.sh
```

请把示例目录替换为实际路径。回退恢复升级前的数据，不会合并升级后新增用户、配置和用量。全新安装没有旧版可回退；失败时保留容器和数据卷供排查。

## 常见排查

```bash
docker ps -a --filter name=freegfw
docker logs --tail 100 freegfw
```

- **面板打不开**：核对容器状态、访问协议、端口以及安全组 / 防火墙。
- **端口占用**：改用未占用端口，并同步修改访问地址和放行规则。
- **旧面板未返回 401**：先完成管理员设置，再核对面板端口。
- **构建失败**：检查服务器网络、可用内存及磁盘空间。

实际服务器部署与 Reality + Vision 端到端运行仍需实机验收；面板启动成功不代表所有节点协议都已验证。
